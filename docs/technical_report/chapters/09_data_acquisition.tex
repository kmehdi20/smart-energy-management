\section{Safety Boundary}

The ESP32 and breadboard operate exclusively at 3.3--5~V DC. All mains-voltage (220~V AC) measurement is performed inside the PZEM-004T module, which provides galvanic isolation between the mains circuit and the TTL serial output. The current transformer (CT) clamp clips around an insulated wire without making electrical contact with the conductor.

\section{Time Resolution}

The ESP32 reads sensors every 10--15 seconds. These raw readings are aggregated to 15-minute averages before database storage. The 15-minute resolution was chosen because it:
\begin{itemize}[nosep]
    \item matches common utility metering intervals,
    \item provides sufficient temporal granularity for load forecasting and optimization,
    \item keeps storage requirements manageable (35,040 rows/year per measurement table),
    \item aligns with the 96-step optimization horizon (24~h / 15~min = 96 steps).
\end{itemize}
