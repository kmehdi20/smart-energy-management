\section{Database Schema}

The database contains 10 tables:

\begin{itemize}[nosep]
    \item \texttt{devices} --- registered data sources (ESP32, simulator)
    \item \texttt{measurements} --- AC load measurements (V, I, P, E, PF, f)
    \item \texttt{pv\_measurements} --- PV voltage, current, power
    \item \texttt{battery\_status} --- battery voltage, current, SOC
    \item \texttt{environmental\_data} --- temperature, humidity, irradiance
    \item \texttt{energy\_flows} --- consolidated energy flow per time step
    \item \texttt{predictions} --- ML forecast values with actuals
    \item \texttt{optimization\_results} --- EMS dispatch schedules (JSONB)
    \item \texttt{alerts} --- anomaly detection alerts with severity
    \item \texttt{daily\_performance} --- aggregated daily metrics
\end{itemize}

All timestamp columns are indexed. The schema supports both SQLite (development) and PostgreSQL (production).

\section{How to Run}

\begin{enumerate}[nosep]
    \item Install dependencies: \texttt{pip install -r backend/requirements.txt}
    \item Generate data: \texttt{python -m simulation.simulator --days 365}
    \item Load database: \texttt{python -m backend.app.services.data\_ingestion --csv ml/data/raw/synthetic\_365d.csv}
    \item Run forecasting: \texttt{python -m ml.forecasting.run --csv ml/data/raw/synthetic\_365d.csv --target consumption}
    \item Run anomaly detection: \texttt{python -m ml.anomaly\_detection.run --csv ml/data/raw/synthetic\_365d.csv}
    \item Run optimization: \texttt{python -m optimization.run --csv ml/data/raw/synthetic\_365d.csv}
    \item Run analysis: \texttt{python -m analysis.run --csv ml/data/raw/synthetic\_365d.csv}
    \item Start dashboard: \texttt{streamlit run dashboard/app.py}
    \item Start API: \texttt{uvicorn backend.app.main:app --port 8000}
    \item Run tests: \texttt{pytest tests/ -v}
\end{enumerate}
